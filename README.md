# 💸 Expense Manager App

A simple and modern Flutter-based Expense Manager application to manage cards and track expenses easily.

---

## 📱 Features

* 💳 Add and manage cards
* 🔒 Hide / Show card number (tap to reveal)
* 💰 Display balance with currency symbols (₹, $, €)
* 📊 View transactions
* 🎨 Clean and modern UI
* 📱 Works on Android & Web

---

## 🛠️ Tech Stack

* Flutter
* Dart
* Provider (State Management)

---

## 🚀 How to Run

```bash
flutter pub get
flutter run
```
